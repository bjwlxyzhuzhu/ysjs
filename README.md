# 镜里知微

按用户提供的 PRD、参考视频与九份《影视鉴赏》课程课件开发的本地应用。界面采用深蓝背景、点阵光影星球、胶囊导航与三栏 3D 放映厅。

## 打开与启动

开发服务地址：**http://127.0.0.1:5173**。首次在本机打开时设置管理员密码（账号 `admin`），之后由管理员分配教师账号。默认关闭免密码体验入口。

环境：Node.js 26、FFmpeg / FFprobe。依赖安装后运行：

```powershell
npm.cmd install
npm.cmd run dev
```

也可用 `npm ci` 按锁定版本安装依赖。将 `.env.example` 复制为 `.env` 后填写本机路径或模型配置，真实密钥不得提交到 Git。

生产模式：

```powershell
npm.cmd run build
npm.cmd start
```

生产服务默认地址：http://127.0.0.1:8787。首次启动会在 `data/initial-accounts.json` 生成 teacher 和 judge01 的随机密码；文件不进入 Git 或前端。teacher 为教师，judge01 为独立体验空间：只读、可上传一个片段。管理员在首次本机访问时自行设置密码，系统只保存加盐哈希；管理员可重置教师密码，原教学数据继续保留。评委账号默认 30 天有效，可在 `.env` 中设置 `JUDGE_EXPIRES_AT` 为比赛实际截止时间。

右上角账号菜单提供“切换账号”和“退出登录”，切换时注销服务端会话并重新加载空白登录页。本仓库不包含本机账号、数据库、API Key、上传视频或学生成绩，首次运行创建独立数据。

## 已实现

- 教师“布置作业”：按对应课程、班级、学年/学期、北京时间截止时间创建任务，填写目标、作业内容、提交要求和五项评分说明；可由课织检索当前教师课程资料生成初稿，教师编辑审核后发布。发布后任务内容与量规锁定，可导出Word任务书在原有班级渠道布置，不要求学生登录。
- 收交与批改闭环：在作业批改选择已发布任务，导入DOCX/ZIP/TXT并核对名单，可先保存收交（不调用模型），再按该任务要求和量规批改；每批最多30份，可分批处理。同一任务每个学号保存一份当前稿，重复保存相同内容不增加版本，修改稿件后旧批改不显示为新稿成绩。
- 班级名单支持粘贴或UTF-8 CSV/TXT导入（每行“学号 姓名”，空格、逗号或Tab分隔，最多1000人）；显示应交、已交、未交名单、AI初稿待复核及教师已复核进度。未填名单时不推测应交与未交。逾期按教师上传保存时间标记，不代表学生实际提交时间。
- 结束收交后保留批改和导出，可重新开放收交。任务、原稿和进度按教师与课程隔离，名单不发送模型、也不导出到学生任务书。同一任务重复批改仅计最新已复核版本的课程过程成绩，历史评分和评价仍保留；未关联任务的旧批次口径保持兼容。
- 教师模块：首页、拉片工作台、备课生成、作业批改、课程知识库、智能体工作室、成效看板、学生成绩、账户安全；管理员可添加课程、分配教师课程和查询学生成绩。
- Three.js 实时点阵星球与虚拟放映厅；拖拽环视、聚焦银幕、真实 VideoTexture 播放、2D 播放器及点击镜头跳转。
- 200MB / 5 分钟片段限制、教学用途与关键帧传输确认。
- FFmpeg 转码、基于场景变化的真实镜头检测、每片精选3–10个教学片段、每段三帧、SSE 增量进度。连续镜头不足3段时补充不同时间位置的观察区间，明确说明它们不是新增剪辑边界；每个新增片段分别执行图像标注。
- 单模型中转接口、临时故障有限重试、结构化响应校验、失败镜头保留人工标注入口。
- 镜头各字段可修改，教师逐镜复核。镜头依据变更后旧材料作废，需重新生成与复核。
- 已复核记录整理模板；配置文本模型后支持 AI 备课生成。
- 备课引用支持唯一镜头序号与知识点页码格式规范化；模型漏引用或结构错误时最多修正一次，修正后仍须通过真实镜头和课程依据校验。界面显示修正阶段，修正会额外产生一次模型请求。网络超时不触发这类内容修正。
- 可编辑 Word 拉片表、课件大纲、五道布鲁姆层级讨论题、板书与导入语，以及 Markdown 导出。每项带镜头 ID 和课件页码依据，材料复核前禁止导出。
- TXT / DOCX / ZIP 作业导入，每批最多30份；可改权重量规、原文引用校验、教师改分与复核、历史批次及共性问题统计。
- 学号、姓名在本机识别与脱敏。按教师、课程、学期和学号归档，保存教师评价和评分修订记录，导出带分数的 Word 能力报告及 CSV。课程过程成绩为已复核作业总分的算术平均，不包含未复核 AI 初稿。
- SQLite 保存独立用户数据；真实前台操作计时、人工用时基线、CSV 导出。测试用独立数据库，未向成效看板灌入演示数据。

## 课程知识库

### 教师课程与自建资料

管理员在“教师账号”中先添加所需课程，再通过“对应课程”下拉菜单分配给教师，也可为已有教师修改课程。教师重新登录后，顶部课程名称、浏览器标题、资料检索和新作业的课程归属均使用分配课程。现有账号默认保留《影视鉴赏》，升级只新增数据库字段与表，不重置账号、密码、成绩或模型配置。改变课程会结束该教师原有会话；原课程资料和成绩保留。

教师在“课程知识库”选择教学大纲来源。自建课程默认“自行上传”，资料同时按教师和课程隔离；即使两个教师教同一门课，也不自动共享资料。《影视鉴赏》可选择内置省级课件加自有资料，或只使用自有资料。

资料类别包括教学大纲、课件、论文、教案、讲义、课堂实录、试卷、习题和批改记录。支持 DOCX、PDF、PPTX、XLSX、UTF-8文本/Markdown/CSV/JSON、SRT/VTT，ZIP可批量导入；文本及ZIP每份不超过20MB，资料包每次最多30份。旧DOC/PPT请另存为新格式。课堂实录支持MP4/WebM/M4A/MP3/WAV，单份不超过200MB；音视频只保存原件，需要教师补充转写文本才能入库。扫描PDF、图片课件无法提取文字时也明确提示补充文本，不冒充识别成功。

上传后先校订、检查个人信息，再点击“确认校订并入库”。知识片段保留原文件名和实际页、幻灯片、段落或工作表位置；批改CSV/XLSX/JSON中可识别的身份列移除，其他资料仍需教师检查。只有确认入库的资料进入智能体检索，未经确认的文件不会作为模型依据。

| 智能体 | 用途 |
|---|---|
| 镜析 · 片段教学智能体 | 关键帧观察、教学价值、课堂提问；拉片和片段对话接入教师资料 |
| 课织 · 教案讲义智能体 | 用教学大纲、课件、教案组织教案与讲义；工作室支持无需视频的文本任务 |
| 阅衡 · 作业批改智能体 | 用试卷、习题、批改范例辅助量规与反馈；批量作业继续由教师复核 |
| 学迹 · 学情分析智能体 | 根据已复核成绩的匿名汇总及课程资料建议教学调整，不将AI初稿计为成绩 |

这里的“训练”采用课程资料检索与角色提示，不进行基础模型参数微调。四个智能体共用原有模型名称和一个API Key；回答和引用需教师核对。测试使用隔离数据库和模型响应夹具，未以模拟响应证明真实模型效果。

### 内置《影视鉴赏》资料

已读取用户提供的专题 1–9，每份 20 页，共 **180 页**。封面不进入检索，共整理为 **171 个页级知识条目**。这不是 171 个经过人工评定的独立概念。

- `knowledge/knowledge.json`：专题、页码、知识条目、原文、关键词及提取状态。
- `knowledge/manifest.json`：九个文件的页数与 SHA-256 校验值。
- `knowledge/source-text/`：去除教师 / 学校身份页脚后的逐页文本。
- `scripts/extract-course.mjs` 与 `scripts/build-knowledge.mjs`：可复现提取流程。

条目 ID 示例：`t2.p04` 对应 `专题2.pdf` 第 4 页的景别内容。原文提取存在字符与排版顺序误差，全部标记为 `source_extracted`，**未宣称逐页人工校订**。知识库界面和输出均提醒此状态。课程原 PDF 未复制进公开目录；用户路径不暴露给浏览器。

## 单模型配置

在侧栏“模型设置”填写模型名称（默认 `qwen3.8-max`）和一个 API Key。空密钥保存表示保留现有值。教师账号才能配置和测试，密钥不回显、不进入浏览器存储。也可设置 `MODEL_NAME` / `MODEL_API_KEY` 环境变量；界面保存值优先。

接口固定为 `https://token.agentone.work/v1/chat/completions`，采用 OpenAI 兼容协议。不同模型与账号的能力以实际探测为准。点击“测试文本与图像能力”会产生两次小规模模型请求，可能计费。图像探测通过后才开启自动视觉分析；仅文本可用时保留切镜、抽帧和人工标注。模型名称存在性和教学分析质量需真实验证。

设置保存在 `data/app.sqlite` 中；SQLite 及其 WAL、备份含密钥，请限制 Windows 目录访问权限，不上传、不公开。旧 `.env` 及历史密钥保持原样，旧 `VISION_*` / `TEXT_*` 不再使用。模型设置不会改动 Codex API 配置。跨境、备案和服务商隐私条款尚未核验，界面不将中转服务宣称为国内合规服务。

无密钥时可本地切镜、抽帧、标注、复核、生成教学模板、导出。静帧不包含声音；AI 声音字段强制为空，声音由教师听辨。批改前需删除身份信息并确认发送文本。成效页用时比值不代表因果意义上的教学效果。

启动：`npm run dev`。检查：`npm test`、`npm run build`。评审与整改记录见 `docs/镜里知微_模拟评审与整改.md`。

## 五视角整改与评价工作台

顶部与侧栏的“学生成绩”“课程知识库”位置已对调。顶部导航采用放大的立体按钮，支持悬停抬升、倾斜和按压反馈；较窄桌面换为两行，手机可横向滚动，系统减少动效时停止这些过渡。

拉片工作台的镜头观察面板可以拖动、收起、隐藏和还原位置，也支持方向键移动与Home还原，移动范围限制在影厅内。镜头标注工作区默认收在右侧边缘，点击展开；收起不会丢失当前编辑，保存和教师复核方式保持原样。桌面抽屉展开时可以继续播放视频与切换时间轴；定位待复核镜头会直接展开标注区。

作业评价、学生能力档案、智能体完整建议和已发布任务支持当前页右侧选项卡面板。能力星环采用按需加载的React/Three.js，支持暂停、系统减少动效和二维降级。教师评分与评价仍需确认复核后导出；Word/CSV包含教师综合评价。

成效均分和成绩星谱仅统计有效、已复核记录，同一任务同一学生取最新已复核版本；AI初稿单独显示。本次批改保存模型、任务与实际提供的资料快照，历史未保存来源不补造引用。正在执行分析、备课或批改时暂时锁定共享模型设置，避免批次混用模型。

按高师比赛五个维度模拟的专业审查及验收边界见[五视角评审与界面整改](docs/五视角评审与界面整改_20261013.md)。没有真实评委评分或获奖承诺；59项自动测试通过，界面验收使用隔离虚构数据与模拟模型。

## 模拟作业与部署说明

### 批改成绩与章节知识点

作业批改保存后，可点击“查看学生成绩”进入当前批次的成绩清单。也可在“学生成绩 → 批改成绩清单”按批次、状态、学号或姓名筛选，勾选记录后导出 CSV；文件包含学号、姓名、课程、学期、作业、分数、复核状态、教师评价与批改建议。没有学号的已批改作业也会显示，明确标为待补全，避免成绩被隐藏。点击“核对名单 / 复核”返回对应批次，补全信息并确认评分。“学生能力档案”仍仅以教师已复核成绩计算课程过程分，可导出 Word 能力报告。成绩清单、学生档案、批改历史和看板共用课程筛选口径，兼容旧记录的课程名称字段。

上传的大纲与资料按实际章节标题归并，不再将每个段落单独列为知识点；每份资料最多18个章节知识点。原始校订文本和出处保留，长章节展示节选，检索仍使用完整章节文字。旧段落知识ID保留为兼容别名，已有镜头引用可继续保存与生成材料。中文文件名仅在确认存在UTF-8/Latin1误读时解码，避免再次破坏正确文件名。

镜头标注的“关联知识点”改为可搜索面板，显示章节标题和资料来源，不显示长UUID；支持按章节、主题或文件名搜索，展开后自动滚动到可见区域，Esc收起，手机宽度受限于标注面板。知识库确认入库后直接显示章节概览。

### 多课程入口与分镜恢复（2026-10-15）

管理员创建教师账号时可不指定课程。教师登录后在无导航栏的首页添加并选择自己的课程，同一账号可使用多门课程；已有课程分配及教学记录继续保留。课程选择在该教师账号的会话间同步；另一页面切换课程后，旧页面的写入会提示刷新。分析、备课或批改执行时须停止或等待完成后再切换课程。课程素材、资料、批改历史与学生成绩按教师和课程隔离。

四个智能体“镜析、课织、阅衡、学迹”独立显示在左侧栏，点击后在当前页展开侧面板，通过“任务、建议、依据”选项卡操作；面板不锁定背景，也不覆盖顶部导航。每个角色的任务草稿分别保留在当前页面会话中，切换课程会清空，避免跨课程混用。

分镜不合适时有六条恢复路径：

1. 在右侧标注区直接修改并保存、复核；知识库尚为空时，可填写“教师补充教学要点”作为明确标注来源的教师依据，继续整理备课模板。
2. “重新识别并替换当前标注”可重做已生成或已复核镜头。成功后需重新复核；失败保留原标注，生成期间的新教师修改不会被迟到结果覆盖。
3. “恢复未完成分析”只处理失败与待处理项，保留有效标注和教师修改。
4. “删除当前分镜”移除不需要的镜头并连续编号，恢复任务不会强行补回已删片段。AI自动精选保持3–10段；教师手动整理后可保留1–10段。
5. “整理重复分镜”按相同ID或近相同时间区间去重，优先保留已复核、已修改记录；不同时间再次出现的相同场景不算重复分镜。
6. “整片重新生成”先保存快照，再重新切选与识别；“撤销上一步”支持最近10步修改、删除、整理及重建。旧备课材料随依据变化失效，必须重新生成并复核；历史作业成绩保留。

低帧率视频的尾帧抽取根据实际帧率限制取样位置，避免视频结束后没有可解码帧导致后续流程中断。上游模型仍可能超时或返回不合理内容，软件提供保留、恢复和人工继续路径，不将请求成功视为教学结论正确。

运行 `node scripts/generate-mock-homework.mjs` 可生成100份虚构学生 Word 作业、总ZIP和4个各25份的可导入ZIP。生成物保存在 `deliverables/`，不进入仓库，不自动调用模型。

Docker 部署：先创建 `.env`，然后运行 `docker compose up -d --build`。使用预构建镜像时拉取 `ghcr.io/bjwlxyzhuzhu/ysjs:latest`，容器内部端口为8787，将持久化目录挂载到 `/app/data`。

### 服务器首次创建管理员

在部署平台的环境变量或 Secret 中设置 `ADMIN_INITIAL_PASSWORD` 为自己选择的8–128位密码，更新镜像后重新部署。服务启动时如果数据库没有管理员，则创建账号 `admin`，只保存加盐哈希。已存在管理员时不重置密码；现有教师、评委、学生成绩及模型配置继续保留。

登录后移除部署环境中的 `ADMIN_INITIAL_PASSWORD` 再重新部署，管理员仍保存在持久化数据库中。不要将真实密码写入GitHub、Dockerfile、工作流或公开配置。`data/initial-accounts.json` 只含旧教师及评委的初始密码，不包含管理员密码。管理员忘记密码不能通过这个初始化变量覆盖，需要单独的受控恢复操作。

本机界面首次设置仍仅限本机连接，公网未登录访客不能通过该接口创建管理员。公网服务没有管理员时，登录页会提示部署管理员配置初始化变量。

仓库包含课程提取文本和页码知识条目，原始 PDF、视频与声音素材需自行提供。公开仓库地址不是运行中的平台地址。
