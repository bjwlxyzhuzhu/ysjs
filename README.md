# 镜里知微

按用户提供的 PRD、参考视频与九份《影视鉴赏》课程课件开发的本地应用。界面采用深蓝背景、点阵光影星球、胶囊导航与三栏 3D 放映厅。

## 打开与启动

开发服务地址：**http://127.0.0.1:5173**。首次在本机打开时设置管理员密码（账号 `admin`），之后由管理员分配教师账号。默认关闭免密码体验入口。

环境：Node.js 26、FFmpeg / FFprobe。依赖安装后运行：

```powershell
npm.cmd install
npm.cmd run dev
```

也可用 `npm ci` 按锁定版本安装依赖。将 `.env.example` 复制为 `.env` 后填写本机路径或模型配置，真实密钥不得提交到 Git。

生产模式：

```powershell
npm.cmd run build
npm.cmd start
```

生产服务默认地址：http://127.0.0.1:8787。首次启动会在 `data/initial-accounts.json` 生成 teacher 和 judge01 的随机密码；文件不进入 Git 或前端。teacher 为教师，judge01 为独立体验空间：只读、可上传一个片段。管理员在首次本机访问时自行设置密码，系统只保存加盐哈希；管理员可重置教师密码，原教学数据继续保留。评委账号默认 30 天有效，可在 `.env` 中设置 `JUDGE_EXPIRES_AT` 为比赛实际截止时间。

右上角账号菜单提供“切换账号”和“退出登录”，切换时注销服务端会话并重新加载空白登录页。本仓库不包含本机账号、数据库、API Key、上传视频或学生成绩，首次运行创建独立数据。

## 已实现

- 教师模块：首页、拉片工作台、备课生成、作业批改、课程知识库、成效看板、学生成绩、账户安全；管理员有教师账号管理和学生成绩查询界面。
- Three.js 实时点阵星球与虚拟放映厅；拖拽环视、聚焦银幕、真实 VideoTexture 播放、2D 播放器及点击镜头跳转。
- 200MB / 5 分钟片段限制、教学用途与关键帧传输确认。
- FFmpeg 转码、基于场景变化的真实镜头检测、每片精选3–10个教学片段、每段三帧、SSE 增量进度。连续镜头不足3段时补充不同时间位置的观察区间，明确说明它们不是新增剪辑边界；每个新增片段分别执行图像标注。
- 单模型中转接口、临时故障有限重试、结构化响应校验、失败镜头保留人工标注入口。
- 镜头各字段可修改，教师逐镜复核。镜头依据变更后旧材料作废，需重新生成与复核。
- 已复核记录整理模板；配置文本模型后支持 AI 备课生成。
- 备课引用支持唯一镜头序号与知识点页码格式规范化；模型漏引用或结构错误时最多修正一次，修正后仍须通过真实镜头和课程依据校验。界面显示修正阶段，修正会额外产生一次模型请求。网络超时不触发这类内容修正。
- 可编辑 Word 拉片表、课件大纲、五道布鲁姆层级讨论题、板书与导入语，以及 Markdown 导出。每项带镜头 ID 和课件页码依据，材料复核前禁止导出。
- TXT / DOCX / ZIP 作业导入，每批最多30份；可改权重量规、原文引用校验、教师改分与复核、历史批次及共性问题统计。
- 学号、姓名在本机识别与脱敏。按教师、课程、学期和学号归档，保存教师评价和评分修订记录，导出带分数的 Word 能力报告及 CSV。课程过程成绩为已复核作业总分的算术平均，不包含未复核 AI 初稿。
- SQLite 保存独立用户数据；真实前台操作计时、人工用时基线、CSV 导出。测试用独立数据库，未向成效看板灌入演示数据。

## 课程知识库

已读取用户提供的专题 1–9，每份 20 页，共 **180 页**。封面不进入检索，共整理为 **171 个页级知识条目**。这不是 171 个经过人工评定的独立概念。

- `knowledge/knowledge.json`：专题、页码、知识条目、原文、关键词及提取状态。
- `knowledge/manifest.json`：九个文件的页数与 SHA-256 校验值。
- `knowledge/source-text/`：去除教师 / 学校身份页脚后的逐页文本。
- `scripts/extract-course.mjs` 与 `scripts/build-knowledge.mjs`：可复现提取流程。

条目 ID 示例：`t2.p04` 对应 `专题2.pdf` 第 4 页的景别内容。原文提取存在字符与排版顺序误差，全部标记为 `source_extracted`，**未宣称逐页人工校订**。知识库界面和输出均提醒此状态。课程原 PDF 未复制进公开目录；用户路径不暴露给浏览器。

## 单模型配置

在侧栏“模型设置”填写模型名称（默认 `qwen3.8-max`）和一个 API Key。空密钥保存表示保留现有值。教师账号才能配置和测试，密钥不回显、不进入浏览器存储。也可设置 `MODEL_NAME` / `MODEL_API_KEY` 环境变量；界面保存值优先。

接口固定为 `https://token.agentone.work/v1/chat/completions`，采用 OpenAI 兼容协议。不同模型与账号的能力以实际探测为准。点击“测试文本与图像能力”会产生两次小规模模型请求，可能计费。图像探测通过后才开启自动视觉分析；仅文本可用时保留切镜、抽帧和人工标注。模型名称存在性和教学分析质量需真实验证。

设置保存在 `data/app.sqlite` 中；SQLite 及其 WAL、备份含密钥，请限制 Windows 目录访问权限，不上传、不公开。旧 `.env` 及历史密钥保持原样，旧 `VISION_*` / `TEXT_*` 不再使用。模型设置不会改动 Codex API 配置。跨境、备案和服务商隐私条款尚未核验，界面不将中转服务宣称为国内合规服务。

无密钥时可本地切镜、抽帧、标注、复核、生成教学模板、导出。静帧不包含声音；AI 声音字段强制为空，声音由教师听辨。批改前需删除身份信息并确认发送文本。成效页用时比值不代表因果意义上的教学效果。

启动：`npm run dev`。检查：`npm test`、`npm run build`。评审与整改记录见 `docs/镜里知微_模拟评审与整改.md`。

## 模拟作业与部署

运行 `node scripts/generate-mock-homework.mjs` 可生成100份虚构学生 Word 作业、总ZIP和4个各25份的可导入ZIP。生成物保存在 `deliverables/`，不进入仓库，不自动调用模型。

Docker 部署：先创建 `.env`，然后运行 `docker compose up -d --build`。使用预构建镜像时拉取 `ghcr.io/bjwlxyzhuzhu/ysjs:latest`，容器内部端口为8787，将持久化目录挂载到 `/app/data`。

### 服务器首次创建管理员

在部署平台的环境变量或 Secret 中设置 `ADMIN_INITIAL_PASSWORD` 为自己选择的8–128位密码，更新镜像后重新部署。服务启动时如果数据库没有管理员，则创建账号 `admin`，只保存加盐哈希。已存在管理员时不重置密码；现有教师、评委、学生成绩及模型配置继续保留。

登录后移除部署环境中的 `ADMIN_INITIAL_PASSWORD` 再重新部署，管理员仍保存在持久化数据库中。不要将真实密码写入GitHub、Dockerfile、工作流或公开配置。`data/initial-accounts.json` 只含旧教师及评委的初始密码，不包含管理员密码。管理员忘记密码不能通过这个初始化变量覆盖，需要单独的受控恢复操作。

本机界面首次设置仍仅限本机连接，公网未登录访客不能通过该接口创建管理员。公网服务没有管理员时，登录页会提示部署管理员配置初始化变量。

仓库包含课程提取文本和页码知识条目，原始 PDF、视频与声音素材需自行提供。公开仓库地址不是运行中的平台地址。
