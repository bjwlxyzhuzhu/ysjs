# 三帧视觉请求失败排查

2026-10-10，模型 `qwen3.8-max`，接口 `https://token.agentone.work/v1/chat/completions`。

观察：保存配置的文本、小图探测均通过，但片段前四镜的标注请求失败。历史错误将所有网络问题统一显示为“超时或网络不可达”，无法还原每次失败的底层原因。第一镜三张JPEG分别约15KB、23KB、23KB；原知识上下文约6338字符，不足以断定是图片大小导致。

整改：真实视觉分析等待上限从60秒延长到180秒；输出限制2048 token，课程上下文只提供ID、标题、摘要及来源；区分超时、DNS、连接重置等安全错误提示；临时连接重置有限重试；超时不自动重发，避免重复费用。

新增教师专属 `POST /api/shots/:id/analyze` 及“重试当前镜头（可能计费）”按钮。仅重试未修改的人工待标注镜头；复用现有三帧、镜头ID和时间轴；服务端再次检查教师修改，避免覆盖并发编辑。不重切视频、不宣称恢复中断任务尚未抽取的镜头。

真实验证：对原失败片段第一镜调用一次重试，HTTP200，114秒，返回 `ai_draft`，error=null，模型返回置信度0.7。这是接口成功证据，不是准确率证据。114秒超过原60秒上限，支持旧超时设置是主要原因的判断，但不证明历史每次网络失败都为超时。

15项自动化测试及生产构建通过；追加集成验证覆盖无图像配置503、未知镜头404、已复核镜头409、评委403。模型测试使用模拟请求；上述114秒结果为真实请求。剩余失败镜头尚未再次调用，用户可逐镜重试，可能产生服务商费用。AI结果仍需教师复核。

原片段总任务还有“服务重启导致任务中断”状态。单镜重试修复已有镜头，不等同完整视频任务恢复；整体重试会重新切镜，应先保留教师已修改记录。密钥未输出或写入源码。
