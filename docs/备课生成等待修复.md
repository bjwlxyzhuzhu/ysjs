# 备课生成等待修复

日期：2026-10-10。用户反馈两次点击“生成备课材料”后仍显示等待，尚无材料。

静态检查发现：页面只检查镜头已复核，后端还检查分析任务锁，存在可点击后被拒绝的状态差异。备课同步HTTP请求使用通用文本模型的60秒上限、2048 token输出预算，错误仅短暂提示，页面缺少持久进度和恢复入口。没有证据能还原用户前两次调用的全部错误，因此不把其每次失败都归因于同一个原因。

整改：备课改为持久化后台任务，POST立即返回202；按教师及片段复用进行中的任务，重复点击不启动第二次模型调用；前端定时查询状态，显示阶段和等待秒数，重新打开页面可以找回进度。异常保存为failed并展示具体原因；服务重启将未完成任务标为失败，不再永久显示生成中。

长篇备课模型请求设置180秒等待与6144 token预算。输入只提供复核镜头的教学字段与精简知识来源，响应截断明确报错，不保存不完整材料。生成期间若镜头依据变动，拒绝保存旧依据。前后端均以完成教学精选、全部教师复核为生成前提。无需模型的模板整理作为明确的可选操作，不能冒充AI生成。

验证：21项测试通过，包含生成任务去重、成功查回、失败持久化、权限隔离、截断检测及真实FFmpeg/DOCX流程。生产构建通过，3D资源包仍有体积提示。

真实模型验证：连续两次POST返回202且同一个任务ID，仅启动一次模型调用；116秒后completed并成功保存备课材料：10个镜头、5页课件大纲、5道讨论题、板书和导入。116秒超过旧60秒上限，支持长篇请求等待设置偏紧的判断。材料状态为AI初稿、未复核，未代替教师确认或导出。
