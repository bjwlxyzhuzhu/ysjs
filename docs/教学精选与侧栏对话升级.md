# 教学精选与侧栏对话升级

2026-10-10。用户反馈：44个镜头逐一调用模型过慢，提问框没有真正对话，刷新无法重新识别。

排查发现真实失败记录包含HTTP524，表示中转接口等待上游响应超时；任务仍处于第7/44镜队列，并非系统只支持前三镜。现有提问入口只是本地关键词检索，未调用大模型。浏览器刷新只重载界面，不重发模型分析。

## 改动

- 教学精选：本地检测画面变化，再取不超过20个候选做缩略图总览；由同一图像模型筛选有叙事或教学价值的片段，提供教学理由。正常最多10个片段，每个片段用首、中、尾三帧深入分析，不再对所有检测到的镜头逐一请求模型。
- 已复核或编辑片段优先保留，其余旧镜头归档。已人工保护的片段超过10个时保留全部，不擅自删除。无图像服务时明确标为本地候选，不能宣称AI精选。候选抽样是成本折中，不能保证覆盖每个有教学价值的瞬间。
- 新增“AI重新精选与识别”“停止当前分析”；后台处理期间提供状态解释。保留单片段重试入口及教师修改保护。
- HTTP524/504明确提示上游超时，不自动重复计费请求；模型连续失败两次暂停后续调用，避免对数十个镜头重复失败。
- 右侧教学助教对话：模型结合当前片段、一个关键帧、课程知识和最多8条脱敏历史回答。支持多轮、Enter发送、Shift+Enter换行、中文输入法组合输入、等待状态、错误展示与问题保留。文字和关键帧按已有模型授权发送，建议由教师复核。
- 知识引用限制在提供的真实ID集合内；未复核镜头标注明确属于推断，无音轨不判断声音。

## 验证

18项测试通过：真实FFmpeg与DOCX工作流、恢复保留教师记录、候选数量边界、精选真实ID与理由校验、524不重试、对话输入校验及缺模型错误。生产构建通过，3D场景包仍有体积提示。

1440×1000桌面和390×844手机实际界面验证：侧栏打开、回车提交、模拟回答显示、无页面异常。浏览器测试用模拟回复避免额外计费，该项不等同真实模型回答质量验收。截图位于visualizations的teaching-qa目录。

真实验证：现有用户片段的AI精选已成功，44个候选缩减为10个教学片段，34条非精选旧记录归档，3个已复核片段保留。后续逐片段分析仍在后台进行，不把全部标注写成已完成。真实模型对话接口HTTP200，23秒返回非空回答；未输出密钥、上传学生资料或声称回答准确率已验证。

重选后的新帧使用唯一文件名，避免覆盖已有复核片段图像。完成教师复核可清除模型失败提示，但中断未完成或待重新精选任务仍不能导出。最终修复后已按缓存的10个精选结果继续后台分析，不再次调用精选模型。
